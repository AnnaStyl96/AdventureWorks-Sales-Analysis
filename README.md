# AdventureWorks Sales Analysis | Power BI

## Project Overview

This project presents an interactive sales analysis developed in Microsoft Power BI using the AdventureWorks dataset.

The objective was to analyze sales performance, profitability, product rankings, and geographical trends while applying DAX calculations and time intelligence techniques.

The report consists of four pages, combining practical DAX exercises with an interactive sales dashboard.

## Tools & Technologies

- Microsoft Power BI Desktop
- Power Query
- DAX (Data Analysis Expressions)
- Data Modeling
- Microsoft Excel
- Data Visualization

## Key Metrics

The analysis covers the following overall results:

| Metric | Value |
|---|---:|
| Total Sales | 109.81M |
| Total Profit | 12.55M |
| Profit Margin | 11.43% |
| Top 5 Products Sales | 18.98M |

## Report Pages

### 1. DAX Practice

Explores DAX calculations and filter context through:

- `CALCULATE`, `FILTER`, `ALL`, and `ALLSELECTED`
- `KEEPFILTERS`
- Sales and cost calculations
- Country-based comparisons
- Profit margin analysis
- Interactive filters

### 2. Time Intelligence

Analyzes sales performance over time using:

- `TOTALYTD`
- `SAMEPERIODLASTYEAR`
- `DATEADD`
- Previous-year sales comparisons
- Month-over-Month (MoM) Growth
- Year-over-Year (YoY) Growth
- Year-to-Date (YTD) Growth

### 3. Advanced DAX

Demonstrates more advanced calculations, including:

- `DATEADD` vs. `PARALLELPERIOD`
- Product ranking with `RANKX`
- Differences between `ALL` and `ALLSELECTED`
- Dynamic ranking based on filter selections

### 4. Sales Performance Dashboard

An interactive dashboard featuring:

- Total Sales, Total Profit, and Profit Margin KPIs
- Monthly sales trends
- Top 10 products by sales
- Sales performance by country
- Sales distribution by product category
- Fiscal year and country slicers

## Key Insights

- Total sales reached approximately 109.81 million.
- The overall profit margin was approximately 11.43%.
- The United States generated the highest sales among the countries analyzed.
- Bikes represented the largest product category by sales.
- Mountain-200 product variants were among the highest-selling individual products.
